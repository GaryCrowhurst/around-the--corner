# Around the Corner — Interactive 3D differential & narrated tour

This is the original Three.js differential simulation, complete with the narrated 3D tour and a link to the published video:

https://youtu.be/iwMyDzyk91o

## Open

Open `index.html` in Chrome or Edge. Three.js is loaded from a CDN, so an Internet connection is required. The tour voiceover is embedded in the HTML.

## Player

Play/Pause, Restart, Seek and Fullscreen control the existing narrated tour. `Explore 3D model` leaves tour mode and returns to the interactive simulator. `Watch on YouTube` opens the published explainer in a new tab.

There is no video recorder or download/capture logic in this edition. The mobile player reorganises its controls into two rows to avoid button overlap.

## Deployment

To update your GitHub Pages site, back up the existing HTML and replace its `index.html` with the included one, then commit/push.
